# EduGenie – AI

EduGenie AI is a responsive educational assistant project designed for a college mini project.

## Features
- Student dashboard
- Personalized study plan
- Study progress overview
- Smart notes/resource section
- AI quiz concept
- AI tutor chat interface
- Exam preparation section
- Responsive design

## Run
Open `index.html` in Chrome/Edge, or use VS Code with Live Server.

## Real AI integration
The included AI tutor is an offline JavaScript demo. For a real AI implementation, connect the frontend to a backend API using Gemini/OpenAI and keep the API key on the server, not in browser JavaScript.

## Suggested project modules
1. Student authentication
2. AI tutor
3. Study planner
4. Notes summarizer
5. Quiz generator
6. Progress tracker
7. Admin/database module

Educational project only; AI-generated answers should be checked against reliable academic sources.
